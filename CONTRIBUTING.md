# Contributing Guidelines

Thank you for your interest in contributing. Please read through this document
before submitting any issues or pull requests.

## Reporting Bugs/Feature Requests

Use the GitHub issue tracker to report bugs or suggest features. When filing an
issue, please check existing open and recently closed issues, and include as much
detail as you can: a reproducible test case, the version/environment in use, and
anything unusual about your setup.

## Contributing via Pull Requests

1. Fork the repository and work against the latest `main`.
2. Modify the source; please focus on the specific change you are contributing.
3. Ensure local tests pass (`pytest`) and linting is clean (`ruff check`).
4. Commit with a clear message and open a pull request, answering any default
   questions in the PR template.

## Code of Conduct
